# 🏀 NBA Players Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on NBA player data using Python. It explores player ratings, team information, physical attributes, and other player details through data cleaning, statistical analysis, and visualizations.

## 🎯 Objectives
- Understand and explore NBA player data.
- Identify and handle missing values.
- Analyze player ratings and physical attributes.
- Visualize data distributions and relationships.
- Extract meaningful insights from the dataset.

## 🛠️ Technologies Used
- **Python**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Google Colab / Jupyter Notebook** – Project development

## 📂 Project Structure
```text
NBA-Players-EDA/
│
├── NBA EDA PROJECTS.ipynb
├── nba.csv
└── README.md
```

## 📊 Key Analysis
1. **Data Exploration:** Examined dataset dimensions, column names, data types, and statistical summaries.
2. **Data Cleaning:** Identified missing values and handled missing entries in the team and college columns.
3. **Player Rating Analysis:** Used a bar chart to compare the top 10 players by rating.
4. **Rating Trends:** Created a line plot to examine ratings across the first 20 players.
5. **Rating Distribution:** Used a histogram to understand the distribution of player ratings.
6. **Height vs. Weight:** Created a scatter plot to explore the relationship between player height and weight.

## 📈 Key Learnings
- Practiced data cleaning and preprocessing using Pandas.
- Learned to explore numerical and categorical variables.
- Developed data visualization skills using Matplotlib.
- Improved understanding of distributions, comparisons, and relationships in real-world datasets.
- Gained practical experience in performing EDA with Python.
